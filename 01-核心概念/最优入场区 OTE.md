# 最优入场区 OTE (Optimal Trade Entry)

> 回撤 62%~79% 的"机构接单区"

## 核心概念

- **OTE**:从一段行情起点到终点的回撤区间,**61.8%~79%**(斐波那契)
- 机构倾向在这个深度回撤区完成加仓,然后继续原方向
- 是 ICT 里"等回调入场"的标准答案

## 识别规则

1. 确认一段**清晰的推动行情**(起点 A → 终点 B)
2. 从 A 到 B 拉斐波那契回撤
3. 关注 0.618 / 0.705 / 0.79 三个价位

## ⏱️ 时间条件(何时有效)

- **回撤要快**:价格应在 2~5 根 K 线内到达 OTE——慢吞吞的深回撤说明动能不足
- OTE 触及时间越接近 [[Kill Zone 交易时段]] 越有效(时间+价格同步)
- 纽约上午的 OTE 回踩成功率 > 尾盘;尾盘 OTE 不做
- 价格在 OTE 区横盘超过 5 根 K 线 = 放弃或降级处理

## 交易应用

- 价格回撤到 OTE 且出现**反转信号**(如 [[订单块 Order Block]] / [[公允价值缺口 FVG]] 触及)→ 入场
- 止损:OTE 下方(或 OB 外)
- 不追价,等价格"来找你"

## 关联

- [[订单块 Order Block]] — OTE 与 OB 重叠 = 黄金入场区
- [[公允价值缺口 FVG]] — FVG 50% 与 OTE 重叠更佳
