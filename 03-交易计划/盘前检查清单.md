# 盘前检查清单

> 每次开盘前 5 分钟过一遍,全部勾选才允许交易

## 🔍 市场环境

- [ ] 今天有没有重大数据/新闻?(非农/CPI/央行讲话 → 当天降风险或不做)
- [ ] 当前处于哪个 [[Power of 3]] 阶段?(A 积累 / M 操纵 / D 派发)
- [ ] 日线级别方向?(上/下/横盘)

## 📍 关键价位

- [ ] 上一日高/低点(主要流动性目标)
- [ ] 亚洲时段区间(08:00-15:00 标出)
- [ ] 最近的 [[订单块 Order Block]] / [[公允价值缺口 FVG]](候补入场区)

## 🎯 今日计划

- [ ] 哪个 [[Kill Zone 交易时段]] 做?(伦敦 15:00 / 纽约 21:30)
- [ ] 用什么模型?([[2019模型]] / [[Silver Bullet]])
- [ ] 入场条件写清楚(扫荡哪个流动性 + 回踩哪里)
- [ ] 止损位?目标位?盈亏比 ≥ 2:1?
- [ ] 最大亏损额度(今日只允许亏多少)

## 🧠 心态

- [ ] 昨天交易状态如何?今天不带情绪进场
- [ ] 只做计划内的交易,错过就错过

> 勾选完成 = 把计划贴到 [[交易计划模板]] 再开盘
