# 2019模型 (2019 Model)

> 一整套"亚洲积累→伦敦扫荡→纽约延续"的日内交易流程

## 流程

1. **亚洲时段(08:00-15:00)**:价格在窄幅区间震荡 → 标记区间高低点(流动性积累)
2. **伦敦开盘(15:00)**:价格突破亚洲区间一侧,扫掉另一侧流动性(通常先假突破)
3. **回踩确认**:扫荡后价格回到 [[订单块 Order Block]] / [[公允价值缺口 FVG]] 附近
4. **纽约延续(21:30)**:若方向未变,纽约开盘顺势延续 → 在 OTE 加仓/入场

## 入场条件(全部满足才做)

- [ ] 亚洲区间清晰可标记
- [ ] 伦敦时段发生流动性扫荡(假突破并收回)
- [ ] 回踩至 OB 或 FVG 且有结构确认(CHoCH)
- [ ] 处于 [[Kill Zone 交易时段]] 内

## 出场管理

- 目标 1:亚洲区间对面(1R)
- 目标 2:上一日高点/低点(2R+)
- 移动止损至入场 OB 外沿
