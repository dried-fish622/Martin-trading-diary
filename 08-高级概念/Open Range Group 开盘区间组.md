# Open Range Group (开盘区间组)

> 每日 9:30 开盘与昨日收盘形成的 group,PD Array 类 DOL

## 核心概念

- **Open Range Group**:每日 9:30(纽约开盘)与昨日收盘之间形成的价格组
- 属于 [[流动性目标]] C 类(PD Array 类)的 DOL
- 开盘区间的边界是重要的流动性/失衡位置

## 识别规则

1. 标记昨日收盘价
2. 标记今日 9:30 开盘(纽约时间)后形成的价格区间
3. 该 group 的边界 = 潜在目标/支撑阻力

## 交易应用

- 开盘 group 边界常被扫荡(止损猎杀)
- 价格回补开盘 group = 常见的首段交付
- 结合 [[首次呈现模型]] / [[ICT 2025 模型]]:开盘区间是流动性来源

## ⏱️ 时间条件

- 9:30 纽约开盘(北京时间 21:30,夏令时 20:30)
- 与 [[Kill Zone 交易时段]] 的纽约时段对应
