# Turtle Soup (海龟汤)

> 止损被拿但失衡没完全填 = 市场不想去那里 = 反转前奏

## 核心概念

- 价格留下**没填完的失衡**,止损被拿但失衡仍没完全填
- 说明市场不想去那里 → 方向确认后用结构入场
- 时间和流动性让概率更高

## 识别规则

1. 更高周期位上有流动性被扫(卖止损/买止损扫荡)
2. 价格清掉止损(如第 3 根 K 低点)却没完全回补失衡
3. 反转信号出现

## 交易应用

- **看涨 Turtle Soup**:扫掉做出来的低点再打进 BISI,然后反转切到看涨
- 对短期 SSL 的扫荡 → 反转入场
- 时间 = 纽约时段,HTF 方向与流动性目标看涨时概率更高
- 常作为 [[Rejection Block]] 的前置信号

## ⏱️ 时间条件

- 纽约时段(NY Session)最有效
- 与 [[Kill Zone 交易时段]] 配合
