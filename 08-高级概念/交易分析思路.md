# 交易分析思路

> 完整的自上而下分析流程(2026-08-30 用户修正版)
> 8 步:方向→源头→位置→DOL→扫荡→结构→入场→管理

## 完整流程

```
① 定方向 —— 先看大周期
     ↓
② 定源头 —— 价格从哪里来?
     ↓
③ 定位置 —— 价格现在在哪?
     ↓
④ 定流动性目标(DOL)
     ↓
⑤ 等扫荡 (Stop Hunt)
     ↓
⑥ 确认结构
     ↓
⑦ 找精度入场 (PD Array)
     ↓
⑧ 执行 + 管理
```

## ① 定方向:先看大周期

- 周线:[[Smart Money 一周走势]](周高低 = 主要流动性目标)
- 日线:[[Daily Bias]](IPDA 20天区间定方向)
- 判断溢价区/折价区:[[PD Array 价格交付阵列]]
- 相关市场核对:[[SMT 对称性]]

## ② 定源头:价格从哪里来?

问自己(读叙事):

- [ ] 是否刚扫过流动性?(PDH/PDL, equal highs/lows)
- [ ] 是否刚回补失衡?(缺口被填)
- [ ] 是否刚留下位移腿?(急涨急跌)
- [ ] 是从折价区还是溢价区过来的?

> 目的:知道价格已经完成了什么,判断接下来要做什么

## ③ 定位置:价格现在在哪?

问自己:

- [ ] 我在溢价区还是折价区?
- [ ] 靠近流动性还是在中间?
- [ ] 靠近失衡还是公允价值?

> 目的:判断当前位置是否适合入场(靠近目标 = 等,靠近失衡 = 观察)

## ④ 定流动性目标 (DOL)

**先知道价格最可能去够哪里**,这是第一条交战规则。用四分类逐项排查:

### A. 流动性类
- 相等高低点 (Equal Highs/Lows)
- 前一日高/低 (PDH/PDL)
- 周高/周低
- 清楚的止损堆 ([[止损堆 Stop Clusters]])

### B. 失衡类
- [[公允价值缺口 FVG]]:BISI(买侧失衡)/ SIBI(卖侧失衡)

### C. PD Array 类
- NWOG(新周开盘缺口,见 [[NWOG-NDOG 开盘缺口]])
- NDOG(新日开盘缺口,见 [[NWOG-NDOG 开盘缺口]])
- Open Range Group(9:30 开盘与昨收 group,见 [[Open Range Group 开盘区间组]])
- 首次出现的 / 新鲜的 PD Array

### D. 时间类
- 369 时间周期的高低点([[369 时间周期]])
- Session 高低点(时段高低)

> ⚠️ **核心原则:DOL 必须顺着更高周期订单流;看不清明确 DOL → 没有交易**
> 详解见 [[流动性目标]]

## ⑤ 等扫荡 (Stop Hunt)

**价格必须先清掉对面止损**,不扫不动。扫荡为潜在的交付状态变化提供燃料。

### 什么是止损扫荡
- 止损猎杀(Stop Hunt)发生在更高周期位(PDH/PDL/区间极值/时段高低点)附近
- 要扫**有意义的 HTF 或相关 LTF 摆动**;随机高低点无意义
- 扫荡把对面止损做出来,困住对面交易者

### 关键认知
- **单独的流动性扫荡并不能确认 MSS**——它只是燃料
- 扫荡之后必须跟随位移(CISD),即价格以实体收盘离开扫荡区,并与 HTF 方向对齐
- 例:价格在 HTF PD Array(PDL)附近的高点/低点扫荡,随后出现位移向下离开扫荡区

### 关联模型
- [[Turtle Soup]]:止损被拿但失衡没填 = 反转前奏
- [[第一枚 Presented FVG]] / [[Silver Bullet]]:开盘扫荡后第一机会
- 扫荡在 [[Kill Zone 交易时段]] 内最有效

## ⑥ 确认结构

**等结构确认,不猜顶底**。识别结构切换的 ICT 操作顺序:

### MSS 进阶确认序列(来自原文)
1. **流动性被拿**(Turtle Soup)
2. **位移**(实体收盘,CISD)
3. **PD Array 反应**(FVG / OB / Breaker)
4. **新交付继续**
5. ⚠️ 若上述序列被破坏,则 **MSS 无效**

### 关键认知
- 扫荡 → 位移(CISD)是确认核心:价格以实体收盘离开扫荡区,并与 HTF 方向对齐
- 位移 = 实体收盘离开扫荡区(不是影线)
- PD Array 反应 = 价格在 FVG/OB/Breaker 处做出反应

### 确认工具
- [[MSS 进阶]]:打穿 swing = 结构转换
- [[CISD]]:收在反向 K 之下 = 交付状态切换
- [[IFVG 反转缺口]]:实体穿过缺口 = 失衡翻转

## ⑦ 找精度入场 (PD Array)

**确认后在 PD Array 里找最精确位置**。算法在同一段价格交付里会连续给出多个入场模型,通常四种:

### 四种入场模型(来自原文)
1. **Turtle Soup(流动性扫荡)**:更高周期位上流动性被扫,提供反转第一口流动性
2. **IFVG (Inversion FVG)**:低周期用 IFVG 确认 MSS,这是偏好的执行 PD Array;一旦被拿走,即成为偏好的执行
3. **Order Block**:用来加仓并保持与主导订单流对齐
4. **Breaker(突破)**:BSL 不必追价,错过早段几乎总会给第二次机会

### 精度 PD Array 细分
- 经典:[[订单块 Order Block]] / [[公允价值缺口 FVG]] 回踩
- 进阶:[[Breaker 家族]] / [[Reaper FVG]] / [[Unicorn 模型]] / [[Propulsion Block]]
- 叠加:[[最优入场区 OTE]]、[[50%pb 回调]]
- [[Reaper FVG]]:精度 PD Array(形成于 Breaker 内部/冲动腿内部,看涨在折价区/看跌在溢价区)

## ⑧ 执行 + 管理

- 时间:只在 [[Kill Zone 交易时段]] 内
- 模型:[[ICT 2022 模型]] / [[首次呈现模型]] / [[ICT 2025 模型]]
- 目标:下一个流动性池 / [[leg1=leg2]] / [[1MM-2MM]]
- 风控:止损结构外,盈亏比 ≥ 2:1,一次会话一次干净执行
- 复盘:[[复盘模板]] → [[月度统计]]

## 🎯 一句话浓缩

> 先看 HTF 方向 → 读懂价格从哪来、在哪 → 明确 DOL → 等扫荡 → 等结构确认 → PD Array 精度入场 → Kill Zone 内执行 → 复盘迭代
