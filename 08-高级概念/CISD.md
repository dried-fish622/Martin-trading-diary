# CISD (Change in State of Delivery)

> 交付状态切换:一个 Order Block 就是一次交付状态切换

## 核心概念

- **CISD**:交付从看涨切换到看跌(或反之)的确认
- 一个 Order Block 就是一次 CISD
- 价格收在触及高周期位的那根(或一串)看涨 K 线之下 = 开始向流动性目标做看跌重新定价

## 识别规则

1. 市场被一路抬高(看涨交付),打进更高周期 PD Array
2. 点到关键价后,算法要向 REQL 做卖侧交付
3. **签名**:价格重新定价,收在触及高周期位的那根看涨 K 线之下
4. 那根初始看涨 K 的开盘价变成**敏感位**

## 交易应用

- CISD 确认后顺势(交付方向切换)
- 初始 K 开盘价 = 关键参考位
- 与 [[SMT 对称性]] 配合:SMT 是线索,CISD 是确认

## ⏱️ 时间条件

- CISD 多发生在触及 HTF PD Array 之后
- 与 [[Kill Zone 交易时段]] 配合
