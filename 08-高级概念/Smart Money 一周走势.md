# Smart Money 一周走势

> 周线定义的是市场叙事,不是精确入场点(2026-08-30 用户修正)

## 核心概念

- **周线 = 市场叙事**:观察一周的交付倾向,不掐精确入场点
- **首要目标:观察周线区间扩张**,不是去猜周收盘价
- **周开盘是评估价格交付的主要机构参考位**
  - 价格走在周开盘**之上** → 通常暗示派发
  - 价格走在周开盘**之下** → 表示看跌交付

## 周线 PD Arrays 的用法

- 周线 PD Arrays(含 [[订单块 Order Block]] 和失衡)用来**找价格更可能去拿的流动性目标**
- **不是用来掐入场时点**
- 周高低点是本周主要流动性目标,日内价格会去够

## 识别规则

1. 标记周开盘价、周高点、周低点
2. 对比当前价格与周开盘的相对位置(上/下)
3. 观察周线区间扩张方向(向上扩张 = 派发/看涨交付,向下 = 看跌交付)

## 交易应用

- 用周线定 **HTF 叙事方向**,日内交易顺周线方向
- 用周线 PD Array 确定流动性目标,但入场时点交给低周期
- 结合 [[Daily Bias]] 细化到日线方向

## ⏱️ 时间条件

- 周一开盘确立叙事,周五常完成目标(TGIF 回撤)
- 与 [[Kill Zone 交易时段]] 叠加使用
