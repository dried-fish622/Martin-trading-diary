# Daily Bias

> 用 IPDA 数据区间确定日线/周线方向,执行高概率交易的第一步

## 核心概念

- **Daily Bias**:通过 IPDA(Interbank Price Delivery Algorithm)数据区间判断下一步最可能的方向
- 用 **20 天区间**回看:确定 HTF 方向和订单流
- 清楚 Daily Bias 是执行高概率交易最重要的前提
- **首要目标:吃到周线扩张这一段**(2026-08-30 用户补充)

## 识别规则

1. 用 IPDA 数据区间(20天回看)定义 dealing range
2. 判断价格在看涨还是看跌交付区间
3. 核对经济日历:知道流动性和波动何时被预期
4. 得出方向:看涨/看跌/中性

## 交易应用

- 日内交易只顺 Daily Bias 方向
- 周线方向 + 日线方向 + 时段方向三级对齐
- 经济日历核对:大事件日降风险

## ⏱️ 时间条件

- 每日盘前更新
- 周一特别重要(新周开始,回卖侧/买侧交付)
