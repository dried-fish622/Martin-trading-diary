# NWOG / NDOG 开盘缺口

> 新周/新日开盘缺口,PD Array 类 DOL 的重要成员

## 核心概念

- **NWOG (New Week Opening Gap)**:新一周开盘留下的缺口(上周收盘 → 本周开盘)
- **NDOG (New Day Opening Gap)**:新一天开盘留下的缺口(昨日收盘 → 今日开盘)
- 属于 [[流动性目标]] C 类(PD Array 类)的 DOL
- 开盘缺口 = 失衡,算法目标之一就是回补它

## 识别规则

1. 标记上周五收盘价 / 本周一开盘价(周缺口)
2. 标记昨日收盘价 / 今日开盘价(日缺口)
3. 缺口方向 = 潜在交付方向(向上缺口常回补,向下同理)

## 交易应用

- 开盘缺口常是**第一流动性目标**(价格先去够它)
- 结合 [[第一枚 Presented FVG]]:扫荡 + 缺口回补后入场
- 与 [[Smart Money 一周走势]] 配合:周缺口回补是一周交付的一部分

## ⏱️ 时间条件

- NWOG:周一开盘时段
- NDOG:每日开盘时段(对应 [[Kill Zone 交易时段]])
- 缺口越新鲜越有效(首次出现/新鲜 PD Array)
