# A+ 入场清单

> 高概率交易框架:入场前逐项核对,全部满足才是 A+ 设置

## 看跌清单

- [ ] 明确的流动性目标,且与更高周期方向和订单流对齐
- [ ] 清楚 HTF 方向
- [ ] 流动性扫荡发生(止损被拿)
- [ ] 结构确认(MSS/CISD)
- [ ] PD Array 精度入场(IFVG/Breaker/Unicorn 等)

## 看涨清单

- [ ] 明确的流动性目标,与更高周期方向和订单流对齐
- [ ] 清楚 HTF 方向
- [ ] 流动性扫荡发生
- [ ] 结构确认
- [ ] 精度 PD Array 入场

## 使用方式

1. 盘前:确定 [[Daily Bias]] 方向 + 流动性目标
2. 盘中:逐项勾选,缺一项就降级或放弃
3. 入场后:按结构管理(目标 = 下一个流动性池)

## ⏱️ 时间条件

- 全部核对在 [[Kill Zone 交易时段]] 内完成
- 错过窗口不追单
