## 🧭 定位

### 核心框架
- [[PD Array 价格交付阵列]] — 各种高概率区域(OB/FVG/Breaker…)的统称,溢价/折价区

- [[IFVG 反转缺口]] — 旧 FVG 被实体穿过 = 反转 PD Array

- [[Reaper FVG]] — 精度 PD Array(Breaker 内部)
- [[第一枚 Presented FVG]] — 9:31 后扫荡+位移形成的首枚 FVG

### Block 家族
- [[CISD]] — 交付状态切换(Order Block 的本质)
- [[Rejection Block]] — 影线定义的价格区,流动性被拿的位置
- [[Mitigation Block]] — 结构转换前最后一根反向 K
- [[Propulsion Block]] — 延续结构,推动到下一目标
- [[Breaker 家族]] — 高概率 Breaker / Inversion Breaker / 高阶理论
- [[Unicorn 模型]] — FVG 与 Breaker 重叠 = 精确入场

### 时间与统计
