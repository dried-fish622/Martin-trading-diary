# Breaker 家族

> 高概率 Breaker / Inversion Breaker / 高阶 Breaker 理论

## 核心概念

- **ICT Breaker**:流动性扫荡之后形成的交付状态切换
- 价格跑止损、对冲仓位,然后切换订单流时被创造出来
- **Breaker 不是那根扫止损的 K,而是留下来的价格结构**
- 为什么最强:作用在挂单上(专打那些在短期高上方买突破的人)

## 三个进阶

### 1. 高概率 Breaker
- 低周期把 Breaker 当入场时,**不能当独立信号**
- 有效 Breaker 需要高周期参考点、有意义上下文(流动性清洗之后或重要 PD Array 上)
- 没有上下文,形态几乎没价值;**上下文先于一切**

### 2. Inversion Breaker
- 当 Breaker 失败、价格带着与 HTF 叙事对齐的位移穿过它 → 这个 Breaker 反向,充当对面 PD Array
- 只在 HTF 交付已切换且有真正位移之后才成立
- 每个 PD Array 都有反向的一面

### 3. 高阶 Breaker 理论
- Breaker 表示流动性扫荡后的交付状态切换
- 专打不 informed 零售:先上破短期高去够更高周期买止损,真正反转发生在那里

## 交易应用

- 上下文(HTF 方向)先于一切,执行前必须先有底层叙事
- 高概率 Breaker:流动性清洗后 / 重要 PD Array 上
- Inversion Breaker:反转确认后用作趋势延续点

## ⏱️ 时间条件

- 与 [[Kill Zone 交易时段]] 配合
- 盘整中或流动性目标不清楚时不适用 Inversion
