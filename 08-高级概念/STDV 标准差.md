# STDV 标准差

> ICT 量化算法可能把价格跑多远去够流动性的方式,依据结构、波动和时间

## 核心概念

- **STDV**:测量价格通常会离开关键摆动多远,并投影统计上可能的流动性目标
- 锚点:ITL/LTL/HTF 锚点
- **STDV 是**:
  - 流动性目标的投影模型
  - 识别买止损或卖止损可能停在哪的方法
  - 打目标的工具,**不是入场触发**

## 识别规则

1. 找关键摆动(ITL/LTL/HTF 锚点)
2. 用 STDV 投影价格可能跑多远
3. 只在偏差和流动性环境合适时使用

## 交易应用

- **让投影与 Daily Open、流动性目标对齐**
- 用于识别高概率止盈或回撤区域
- 不作为独立入场信号

## ⏱️ 时间条件

- 与 [[FLOUT]] 的时段配合
- 与 [[Kill Zone 交易时段]] 对齐时更有效
