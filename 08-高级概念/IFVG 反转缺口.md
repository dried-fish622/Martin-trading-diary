# IFVG 反转缺口 (Inversion FVG)

> 一枚没守住价格的旧 FVG,被实体收盘穿过 = 失衡翻转向新 PD Array

## 核心概念

- **IFVG**:旧 FVG(失衡)被一根**决定性实体收盘穿过**,预期翻转方向,变成新 PD Array
- 必须先有有效 FVG(三K结构、清楚非重叠)
- 没有有效 FVG 就不可能有 IFVG

## 识别规则

1. 找到有效 FVG(位移形成的失衡)
2. 价格必须**收盘穿过缺口**(不是影线、不是擦边,必须实体收在缺口边界之外)
3. 方向判定:
   - 看涨 FVG + 实体收在下方 → 看跌 IFVG
   - 看跌 FVG + 实体收在上方 → 看涨 IFVG

## 交易应用

- IFVG 是**确认工具**,不是独立设置
- 只在与 HTF 叙事、流动性和位移对齐时使用
- 高概率 IFVG 反转:等结构失败证据,不猜顶底

## ⏱️ 时间条件

- 止损猎杀(Stop Hunt)后概率最高:要扫有意义的 HTF/LTF 摆动
- 与 [[Kill Zone 交易时段]] 配合
