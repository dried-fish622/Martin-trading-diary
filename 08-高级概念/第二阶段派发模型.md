# 第二阶段派发模型 (Stage-2)

> MMXM 里最干净、最高概率的扩张阶段:Stage-2 再派发 / 再吸筹

## 核心概念

- 后半生只能做一种公开过的模型:选 **Market Maker Sell Model 里的 Stage-2 Re-Distribution**(买模型则是 Stage-2 再吸筹)
- 因为这是**算法给出的最干净、最高概率扩张阶段**

## 识别规则

1. 确认处于 MMXM 的 Stage-1(初始派发/吸筹)之后
2. 找到 Stage-2 再派发/再吸筹结构
3. 标记日线 FVG 下沿等 PD Array

## 交易应用

- 左侧溢价区低风险做空(空模型)
- 右侧折价区低风险做多(多模型)
- 用 SMR(日线 FVG 下沿 PD Array)作为参考

## ⏱️ 时间条件

- 与 [[MMXM 做市商模型]] 的周期对齐配合
- 出现在 MMXM 曲线的特定阶段
