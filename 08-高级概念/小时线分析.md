# 小时线分析

> 小时线(1H)的执行框架:确认→对齐→选PDA→目标扩张(2026-08-30 用户提供)

## 核心概念

小时线是**执行层**:周线给叙事,日线给方向,小时线负责找具体入场。

## 分析步骤(4 步)

### 1. 确认哪天形成周高点
- 观察周线区间扩张,确认**哪一天打出周高点**(或周低点)
- 这定义了本周的流动性目标和交付进度

### 2. 等待市场结构与周线对齐
- 等小时线市场结构(swing 结构)与[[Smart Money 一周走势]]周线叙事方向一致
- 不对齐不动,对齐才进入下一步

### 3. 选择入场 PDA
- 在结构对齐后,选择具体的入场 PD Array([[PD Array 价格交付阵列]])
- 例:OB、FVG、Breaker 等(见 [[订单块 Order Block]] / [[公允价值缺口 FVG]] / [[Breaker 家族]])

### 4. 破位周开盘价,目标扩张
- 入场后关注**周开盘价**这一机构参考位(见 [[Smart Money 一周走势]])
- 价格**破位周开盘价** → 确认扩张方向 → 目标 = 周线区间扩张
- 周开盘上破 = 派发/看涨扩张;下破 = 看跌交付
