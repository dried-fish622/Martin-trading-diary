# 大小周期结合

> 晓晓体系的方法论核心:大周期定方向,小周期找入场

## 核心原则

- **5min(或更大)确定市场周期**:趋势/通道/TR,方向明确
- **2min 找精确入场点**:入场更早、止损更小、盈亏比更高
- **入场后回到大周期确认**:周期未变就持有,不被小周期噪音干扰

## 标准流程

1. 5min 判断市场周期和方向(关键前提)
2. 小周期(2min)等信号 K(second entry、failed bo、通道下沿)
3. 小周期入场 → 回 5min 跟踪,周期变了才离场
4. 止盈按大周期结构(ema20、TR 对侧、leg1=leg2)

## 晓晓案例

- 2025.11.11 第 2 笔:5min 振幅太小 → 去 2min 找入场 → 小级别信号入场 → 回到 5min 跟踪
- 2025.12.01:2min k34-k35 强势突破 ema,5min k14 低点抬高 DB → 大小周期都有做多信号 → 挂 50%pb 做多
- 2025.12.04:5min 市场进入宽通道 → 进 2min 找入场,提高盈亏比

## ⏱️ 时间条件

- 大小周期共振(同为趋势)时信号最强
- 大周期 TR、小周期趋势 = 做区间内短线
