# 价格行为策略总览

> 来源:晓晓价格行为复盘合集(2025.10-12, NQ 日内 42 个交易日)+ 10种通道入场方式(中英对照)
> 风格:Al Brooks 式价格行为 + ema20 均线系统,与 ICT 概念互补

## 🧭 核心框架

价格行为 = 市场周期(market regime)+ 信号K线(signal bar)+ 大小周期结合

| 维度 | 内容 |
|---|---|
| 市场周期 | 趋势 / 窄通道 / 宽通道 / TR震荡区间 / 楔形 |
| 信号K线 | 强突破K / 失败突破K(failed bo)/ second entry / 带尾K线 |
| 时间框架 | 5min 定市场周期 → 2min 找入场 → 回 5min 确认周期未变 |
| 止损逻辑 | 结构止损(信号K高低点)/ 逻辑止损(跟随K高点)|

## 📚 策略卡索引

### 通道类(核心,占复盘最多)
- [[窄通道突破]] — 跌破/突破通道下沿/上沿,跟随则继续
- [[窄通道二次延续]] — 通道内回撤后二次入场
- [[宽通道]] — 波动大的通道,回撤入场,1倍盈亏比止盈

### 均线类(ema20 系统)
- [[ema20 支撑与受阻]] — 趋势中首次触及必有反应
- [[failed bo up/down]] — 突破 ema 失败 = 反向入场信号

### 结构类
- [[TR 震荡区间]] — 高抛低吸,突破后回踩确认
- [[2nd leg down/up]] — 强趋势后的第二段,顺势交易核心
- [[leg1=leg2]] — 止盈目标测算
- [[second entry]] — 首次入场失败后的二次机会
- [[楔形 wedge]] — 收敛形态,突破方向入场

### 执行类
- [[大小周期结合]] — 5min 定方向,2min 找点
- [[50%pb 回调]] — gift bar 后的标准回调位
- [[gift bar]] — 大K线后的 50% 反弹规律
- [[1MM/2MM]] — TR 突破后的测量目标
